# Vidrios R-26

Sitio personalizado de Vidrios R-26. Toma como punto de partida la estructura de la demo de vidriero de TuWebEnTresDias y adapta el diseño a sus trabajos, fotos y video.

## Desarrollo

- Sitio estático, sin dependencias externas.
- Fotos y video optimizados y almacenados localmente en el repositorio.
- Navegación móvil, galería ampliable y reproductor de video integrados.
- El enlace de WhatsApp abre una consulta dirigida al número comercial informado.

## Revisión

La vista previa incluye noindex, nofollow para que no se indexe antes de que el cliente apruebe el contenido. Al aprobar la web para su publicación definitiva, actualizar los metadatos y retirar esa directiva.
